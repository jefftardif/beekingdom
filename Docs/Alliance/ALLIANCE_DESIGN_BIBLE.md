# Philosophie

Dans BeeKingdom, l'Alliance n'est pas une simple fonctionnalité.

L'Alliance est le cœur social du jeu.

La plupart des joueurs ne resteront pas plusieurs années parce qu'ils aiment construire une ruche.

Ils resteront parce qu'ils auront trouvé une communauté.

Ils auront des amis.

Des responsabilités.

Des rivalités.

Des souvenirs.

Notre objectif est de créer des Alliances dont les membres seront fiers.

---

# Vision

Une Alliance doit devenir :

une famille,

une équipe,

une nation,

une identité.

Le joueur ne doit jamais dire :

"Je joue à BeeKingdom."

Il doit dire :

"Je fais partie de l'Alliance X."

---

# Les piliers

Toute fonctionnalité d'Alliance devra renforcer au minimum un des piliers suivants.

## Coopération

Les joueurs progressent ensemble.

Aider les autres est toujours récompensé.

---

## Communication

Les échanges doivent être simples.

Chat.

Discord.

Page Web.

Annonces.

Notifications.

Historique.

---

## Identité

Chaque Alliance possède :

- un nom
- un blason
- une bannière
- des couleurs
- une devise
- une histoire
- une réputation

Une Alliance doit être reconnaissable immédiatement.

---

## Progression

L'Alliance évolue.

Pas seulement les joueurs.

L'Alliance possède sa propre progression.

---

## Prestige

Les Alliances accumulent :

- monuments
- trophées
- titres
- records
- accomplissements
- saisons gagnées

L'histoire d'une Alliance doit être visible.

---

# Création d'une Alliance

Créer une Alliance est un accomplissement.

Ce ne doit pas être une décision prise après cinq minutes de jeu.

Le joueur devra satisfaire certaines conditions.

Exemples :

- niveau minimal
- ressources
- quête spécifique

Ces conditions seront définies plus tard.

---

# La Capitale d'Alliance

Chaque Alliance possède une Capitale.

Ce n'est pas un simple menu.

C'est un véritable lieu.

Tous les membres contribuent à son évolution.

---

Palais Royal

Bibliothèque

Temple des Reines

Centre Diplomatique

Salle du Conseil

Jardins Royaux

Entrepôts

Tours de guet

Archives

Trésor

Chaque bâtiment possède :

# Technologies d'Alliance

L'Alliance possède son propre arbre technologique.

Tous les membres contribuent.

Les recherches profitent à toute l'Alliance.

Exemples :

Économie

Militaire

Construction

Récolte

Recherche

Expédition

Commerce

Diplomatie

---

# Contribution

Chaque action aide l'Alliance.

Exemples :

Faire un don.

Aider un membre.

Participer à une guerre.

Construire un monument.

Escorter un convoi.

Participer à un événement.

Les joueurs doivent toujours sentir que leur contribution est utile.

Chaque rôle possède une utilité.

Chef

Bras droit

Officier

Diplomate

Recruteur

Web Manager

Historien

Trésorier

Responsable Événements

Stratège

De nouveaux rôles pourront être ajoutés.

# Web Manager

Le Web Manager est une exclusivité BeeKingdom.

Il administre :

- la page Web officielle
- le recrutement
- les actualités
- Discord
- les candidatures
- les événements
- la galerie

Il se connecte avec son compte BeeKingdom.

Aucun compte supplémentaire.

---

# La page Web d'Alliance

Chaque Alliance possède gratuitement une page officielle.

Elle contient notamment :

Présentation.

Histoire.

Blason.

Bannière.

Galerie.

Discord.

Liste des membres.

Classement.

Succès.

Monuments.

Statistiques.

Recrutement.

Événements.

Actualités.

Toutes les informations sont synchronisées automatiquement avec le jeu.

---

# Discord

Une Alliance peut associer son serveur Discord.

Les membres peuvent rejoindre directement.

Certaines informations pourront être synchronisées.

Le détail sera défini dans un document dédié.

---

# Monuments

Les Alliances débloquent progressivement des monuments.

Exemples :

Monument des Fondateurs.

Temple des Héros.

Jardin Royal.

Statue de la Reine.

Arbre Sacré.

Ils représentent les grandes réussites de l'Alliance.

---

# Diplomatie

Les Alliances peuvent :

être alliées,

être neutres,

être ennemies.

La diplomatie doit devenir une mécanique de gameplay.

---

# Guerres

Les guerres ne doivent pas être de simples affrontements.

Elles racontent une histoire.

Chaque guerre doit laisser une trace.

Statistiques.

Classements.

Historique.

Monuments.

Récompenses.

---

# Histoire

Chaque Alliance possède une chronologie.

Exemples :

Création.

Fusion.

Victoire majeure.

Monument construit.

Événement remporté.

Chef changé.

La page Web affichera cette histoire.

---

# Recrutement

Le recrutement doit être un véritable système.

Les Alliances peuvent définir :

leurs objectifs,

leur langue,

leurs horaires,

leurs exigences,

leurs valeurs.

Les joueurs peuvent postuler directement.

---

# Progression collective

Chaque saison apporte :

de nouveaux objectifs,

de nouvelles récompenses,

de nouveaux monuments.

Une Alliance progresse pendant des années.

---

# Économie

Les Alliances pourront posséder :

un coffre,

des récompenses,

des dons,

des ressources communes,

des projets collectifs.

Le détail sera défini plus tard.

---

# Identité visuelle

Les Alliances doivent être magnifiques.

Leur identité repose sur :

- Blason
- Bannière
- Couleurs
- Devise
- Titres
- Monuments
- Capitale

Le joueur doit être fier d'en faire partie.

---

# Les souvenirs

Les meilleurs souvenirs des joueurs doivent venir de leur Alliance.

Victoire difficile.

Défaite mémorable.

Sauvetage.

Record.

Événement mondial.

Conquête.

BeeKingdom doit fabriquer des histoires.

---

# Philosophie économique

Les Alliances ne doivent jamais devenir pay-to-win.

Les achats pourront concerner :

- personnalisation
- décoration
- prestige
- confort
- outils d'organisation

Jamais la victoire.

---

# Vision finale

Notre objectif n'est pas de créer une fonctionnalité d'Alliance.

Notre objectif est de créer les meilleures communautés jamais vues dans un jeu de stratégie mobile.

Le joueur restera pour ses amis.

Pour son Alliance.

Pour son histoire.

La ruche est son foyer.

L'Alliance est sa famille.

Le Royaume est son aventure.
