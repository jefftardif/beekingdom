Alpha Sprint-009 — Profil Premium des membres de l'Alliance
Contexte

Le Centre d'Alliance atteint maintenant un bon niveau de maturité.

Je souhaite enrichir l'expérience en permettant de consulter le profil d'un membre directement depuis la liste des membres ou le fil d'activité.

Le profil doit devenir la carte d'identité d'un joueur.

Objectif

Créer un profil plein écran du joueur.

Le profil s'ouvre lorsqu'on sélectionne un membre.

Aucune popup.

Même philosophie que le reste du jeu.

Informations affichées

Afficher :

Avatar
Nom
TAG d'alliance
Blason de l'alliance (placeholder)
Rôle
Niveau
Puissance
Date d'entrée dans l'alliance
Dernière connexion
Devise personnelle (placeholder)
Statistiques

Créer une première section contenant :

Abeilles possédées
Ressources collectées
Bâtiments améliorés
Recherches terminées
Aides envoyées
Dons effectués

Des données simulées sont acceptées.

Présence

Ajouter un indicateur visuel.

Exemples :

🟢 En ligne

🏠 Dans la ruche

🌍 Sur la carte

⚔ En combat

🤝 Dans l'Alliance

😴 Hors ligne

L'architecture doit permettre de remplacer facilement ces valeurs par les vraies données serveur.

Actions rapides

Selon les permissions :

💬 Envoyer un message

🤝 Ajouter en ami

📨 Inviter

🚫 Signaler (placeholder)

👑 Promouvoir (si autorisé)

⚔ Exclure (si autorisé)

Présentation

Même langage graphique que le Centre d'Alliance.

Même palette.

Même qualité.

Même style.

Responsive

Optimisé d'abord pour téléphone.

Contraintes

Ne pas développer :

les vrais amis ;
la vraie messagerie ;
les vraies promotions.

Les boutons peuvent ouvrir des placeholders.

Le but est de construire l'architecture de l'écran.

Validation

Vérifier :

ouverture depuis la liste des membres ;
ouverture depuis le fil d'activité ;
retour fluide au Centre d'Alliance ;
adaptation téléphone et PC.
Documentation

Mettre à jour :

Docs/Claude/Claude_Continuation.md
QoL

Ajouter une petite animation d'ouverture du profil :

zoom très léger ;
fondu ;
environ 0,2 seconde.
Ma vision

Le profil d'un joueur doit donner envie d'être consulté.

Quand on clique sur un membre, on doit immédiatement comprendre :

qui il est ;
depuis combien de temps il est là ;
à quel point il est actif ;
quel est son rôle dans l'alliance.

À terme, ce sera aussi l'endroit où s'afficheront les succès, les décorations, les blasons, les Championnes favorites et l'historique du joueur.
