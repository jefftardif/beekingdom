# HERALDRY_BIBLE.md
## BeeKingdom Heraldry Art Bible

**Projet :** BeeKingdom

**Auteur :** Architecte

**Version :** 1.0

**Statut :** Document de référence

---

# Objectif

Cette Bible définit les règles artistiques officielles du constructeur de blasons de BeeKingdom.

Tous les éléments graphiques produits pour le constructeur doivent respecter ce document.

Il constitue la référence absolue pour :

- les graphistes
- les directeurs artistiques
- les intégrateurs Unity
- les futurs collaborateurs

Aucune exception ne doit être introduite sans validation de la Direction Artistique.

---

# Philosophie

Le constructeur de blasons représente l'identité des alliances.

Chaque création doit donner l'impression d'avoir été réalisée par les meilleurs artisans du royaume.

Les joueurs doivent immédiatement ressentir :

- le prestige
- la noblesse
- la puissance
- l'histoire
- la richesse

Un blason BeeKingdom ne doit jamais paraître générique.

# Qualité

Objectif :

Comparable aux meilleurs MMORTS mobiles.

Références :

- Whiteout Survival
- Call of Dragons
- Rise of Kingdoms
- Ant Legion

Sans jamais copier leur direction artistique.

---

# Règles des Backgrounds

Les backgrounds sont des fonds.

Ils ne doivent jamais contenir :

- symbole
- abeille
- couronne
- logo
- animal

Le centre reste toujours libre.

---

# Règles des Banners

Les bannières servent uniquement à afficher le nom de l'alliance.

Le centre reste vide.

Toutes les bannières utilisent :

- la même silhouette
- les mêmes proportions
- le même cadre
- les mêmes rouleaux

Seul le matériau change.

---

# Règles des Borders

Les bordures doivent :

encadrer le blason

sans masquer le background

Leur largeur reste constante.

---

# Règles des Crowns

Les couronnes sont indépendantes.

Elles ne doivent jamais être fusionnées au cadre.

---

# Règles des Symbols

Les symboles sont :

centrés

parfaitement détourés

sans fond

Ils doivent rester lisibles à très petite taille.

---

# Règles des Ornaments

Les ornements sont indépendants.

Ils doivent pouvoir être combinés librement.

---

# Modularité

# Principe fondamental

Tous les éléments du constructeur doivent donner l'impression d'avoir été fabriqués dans le même royaume.

Même lorsqu'ils appartiennent à des collections différentes.

Le joueur ne doit jamais avoir l'impression de mélanger des assets provenant de jeux différents.

Le constructeur doit posséder une identité visuelle immédiatement reconnaissable.

---

# Vision

Le constructeur de blasons n'est pas un simple éditeur graphique.

Il constitue l'identité officielle des alliances de BeeKingdom.

Les joueurs utiliseront leurs créations :

- dans le jeu
- sur Discord
- sur leur site Web
- sur les réseaux sociaux
- dans les événements communautaires

Chaque élément produit doit donc respecter un niveau de qualité suffisant pour représenter durablement l'univers de BeeKingdom.

Cette Bible artistique est le document fondateur garantissant cette cohérence.
