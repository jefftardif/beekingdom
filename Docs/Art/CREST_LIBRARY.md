## BeeKingdom - Heraldry Asset Registry

**Statut :** Vivant

**Auteur :** Architecte

**Version :** 1.0

---

# Objectif

Ce document constitue le registre officiel de tous les éléments graphiques utilisés par le constructeur de blasons de BeeKingdom.

Chaque asset possède :

- un identifiant unique
- un nom
- une collection
- une rareté
- un mode d'obtention

Ce document est la référence utilisée par :

- le Graphiste
- OC
- le Product Owner

---

# Raretés

## 🟢 Commun

Accessible gratuitement.

Disponible dès la création de l'alliance.

---

## 🔵 Rare

Débloqué par la progression.

Exemples :

- Niveau d'alliance
- Succès
- Événements

---

## 🟣 Premium

Disponible dans la boutique.

Peut être vendu individuellement ou dans une collection.

Aucun bonus de gameplay.

---

## 🟡 Légendaire

Très rare.

Obtenu uniquement via :

- saisons
- championnats
- événements spéciaux

Non vendu directement.

---

## 🔴 Exclusif

Récompenses exceptionnelles.

Exemples :

- Fondateur
- Bêta
- Champion mondial
- Événement unique

---

# Règles de conception

Tous les nouveaux assets doivent respecter :

- Direction artistique BeeKingdom
- Style Premium AAA
- Fantasy réaliste
- Mobile First
- Fond transparent
- Compatible Unity
- Même niveau de qualité que la collection Fondation

---

# Règles de monétisation

Les contenus Premium sont exclusivement cosmétiques.

Ils ne procurent jamais :

- bonus
- statistiques
- puissance
- accélération
- avantage PvP

Le prestige peut être acheté.

La puissance se mérite.

---

# Évolution

Cette bibliothèque est destinée à grandir durant toute la durée de vie de BeeKingdom.

De nouvelles collections viendront régulièrement enrichir le constructeur de blasons.

Exemples :

- Royaume Volcanique
- Royaume Céleste
- Royaume Sylvestre
- Royaume Abyssal
- Royaume Draconique
- Royaume des Sables
- Royaume des Tempêtes
- Royaume Hivernal
- Royaume Impérial
- Collections saisonnières
- Collections événementielles

L'objectif est de permettre à chaque alliance de créer un blason véritablement unique tout en conservant une cohérence artistique parfaite.
