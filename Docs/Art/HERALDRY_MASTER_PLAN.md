# Vision

Le constructeur de blasons est l'un des piliers de l'identité de BeeKingdom.

Il ne s'agit pas d'un simple éditeur cosmétique.

Il permet aux alliances de créer une identité visuelle unique qui sera utilisée :

- dans le jeu
- sur les profils publics
- sur les pages Web d'alliances
- sur Discord
- dans les événements communautaires
- dans les compétitions
- dans les tournois
- dans les outils externes

Chaque blason doit être immédiatement reconnaissable comme appartenant à l'univers BeeKingdom.

---

# Objectifs

Le constructeur doit permettre :

- une personnalisation très profonde
- une excellente lisibilité
- une identité visuelle forte
- une évolution pendant plusieurs années

Il doit pouvoir accueillir plusieurs centaines, voire plusieurs milliers d'assets sans perdre sa cohérence.

---

# Principes fondamentaux

Le système repose sur quatre principes.

## 1. Modularité

Chaque famille d'assets est indépendante.

Le joueur construit son blason en assemblant plusieurs éléments.

---

## 2. Collections

Les assets sont regroupés par collections artistiques.

Chaque collection possède sa propre identité.

---

## 3. Rareté

Chaque asset appartient à une rareté officielle.

La rareté influence uniquement le prestige visuel.

Jamais le gameplay.

---

## 4. Évolutivité

Le système est conçu pour accueillir de nouvelles collections pendant toute la durée de vie de BeeKingdom.

# Philosophie

Le constructeur de blasons doit devenir une référence parmi les jeux de stratégie mobiles.

Les joueurs doivent avoir envie de :

- collectionner
- débloquer
- acheter
- gagner
- montrer

leurs créations.

Le blason devient la signature officielle de leur alliance.

---

# Export

Le constructeur permettra à terme :

- export PNG
- export SVG
- partage Discord
- partage Web
- profils publics
- pages officielles d'alliance

---

# Évolution

Le système est pensé pour fonctionner durant plusieurs années.

Chaque nouvelle collection devra respecter :

- la Bible Artistique
- les conventions de nommage
- les règles de modularité
- les niveaux de qualité Premium AAA

---

# Objectif final

Créer le constructeur de blasons le plus complet jamais réalisé dans un jeu de stratégie mobile.

Il devra devenir une fonctionnalité emblématique de BeeKingdom et un élément central de son identité visuelle.
