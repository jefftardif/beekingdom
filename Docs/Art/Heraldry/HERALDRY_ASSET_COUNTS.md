# Objectif

Ce document définit le nombre officiel d'assets que devra contenir chaque collection héraldique.

Ces quantités servent de référence pour :

- le graphiste
- OC
- la monétisation
- les événements
- les saisons
- les futures collections

Une fois validées, elles ne doivent plus être modifiées sans justification majeure.

---

# Philosophie

Chaque collection doit offrir suffisamment de choix pour permettre à chaque alliance de créer un blason réellement unique.

Le constructeur ne doit jamais donner l'impression de recycler toujours les mêmes éléments.

# Philosophie de production

Chaque nouvelle collection devra respecter exactement cette structure.

Exemple :

Collection Volcanique

20 backgrounds

15 bannières

20 bordures

20 couronnes

250 symboles

50 ornements

15 rubans

25 étoiles

10 effets

---

# Évolutivité

Cette structure permet :

- l'ajout de nouvelles collections
- les événements
- les packs premium
- les récompenses saisonnières

sans modifier l'architecture du constructeur.

---

# Règle fondamentale

Les quantités restent fixes.

La créativité se trouve dans les matériaux, les couleurs, les textures, les gravures et les détails artistiques.

Cette stabilité simplifie considérablement :

- le développement Unity
- la maintenance
- les outils d'import
- les interfaces
- la monétisation
- la documentation
